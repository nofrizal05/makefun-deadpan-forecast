# Deadpan Forecast for Vexley

A deadpan weather forecast for a city that does not exist.

## Run

```sh
python3 main.py
```

## Output

```
In Vexley, expect a high of 14°, a low of morale, and scattered drizzle that cancels outdoor plans without ever technically raining.
```

Vexley is entirely fictional. Any resemblance to a real city that cancels
your plans with drizzle that refuses to count as rain is purely coincidental.
